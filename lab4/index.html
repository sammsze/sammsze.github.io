PROJECT 4A:
IMAGE WARPING & MOSAICING

In this project I register photographs taken from a fixed center of projection using homographies, warp them with my own inverse-warping code, and blend them into mosaics. I did not use cv2.findHomography, cv2.warpPerspective, skimage.transform.warp, or similar high-level functions.

A.1: SHOOT THE PICTURES

I shot each set by keeping the camera in place and rotating it, so that the images are related by a projective transform. Each pair has roughly 40-70% overlap.

A.2: RECOVER HOMOGRAPHIES

A homography maps a point p = (x, y, 1) in image 1 to p' = Hp in image 2, where H is 3×3 with 8 degrees of freedom (I fix H[2][2] = 1). Writing out p' = (x', y') after dividing by the third coordinate and rearranging, each correspondence gives two linear equations in the unknowns h = [a, b, c, d, e, f, g, h]:

x*a + y*b + c            - x*x'*g - y*x'*h = x'
            x*d + y*e + f - x*y'*g - y*y'*h = y'

Stacking n correspondences gives Ah = b with A of size 2n×8. With n > 4 the system is overdetermined, so I solve it with least squares (np.linalg.lstsq) to be robust to click noise. I clicked 8 points per pair.

A.3: WARP THE IMAGES (RECTIFICATION)

I implemented warpImageNearestNeighbor(im, H) and warpImageBilinear(im, H) with inverse warping. The output bounding box is found by pushing the four image corners through H. Then for each output pixel I apply H-1 to find where it came from in the source image, and sample there. Pixels that map outside the source are left empty and tracked in an alpha mask. Nearest neighbor rounds to the closest pixel. Bilinear takes the weighted average of the four surrounding pixels.

Nearest neighbor is faster and simple, but it produces jagged, aliased edges, especially along diagonal lines and after heavy magnification. Bilinear is slightly slower because it reads four pixels and blends them per output pixel, but the result is visibly smoother.

A.4: BLEND THE IMAGES INTO A MOSAIC

Procedure. I pick one image as the reference and compute a homography from each other image into the reference frame using my computeH. I then compute the final canvas size from all of the warped image corners and warp every image into that canvas in one shot with bilinear inverse warping. To avoid hard seams, I blend using weights from the distance transform: each pixel's weight is its distance to the nearest edge of its source image (normalized to 0-1), so weight falls off toward the borders. I use a two-band blend: low frequencies (Gaussian blurred, σ=15) are combined with the weighted average, while high frequencies are taken from whichever image has the largest weight at that pixel. This reduces ghosting of fine details while keeping smooth transitions.

WHAT I LEARNED

One thing I noticed was the sensitivity of the homography to click accuracy. It was very difficult to click the points at pixel perfect accuracy, resulting in artifacts in the final output.
