PROJECT #3:
FLOW MATCHING & DIFFUSION MODELS

PART A1: VISUALIZING TRAINING & SAMPLING

1.1 Forward Process & Noisy Inputs

Flow matching defines a continuous path between Gaussian noise $x_0 \sim \mathcal{N}(0, \mathbf{I})$ and clean images $x_1$. Using linear optimal-transport (OT) interpolation, intermediate noisy states $x_t$ at time $t \in [0, 1]$ are generated via:

$$x_t = (1 - t)\epsilon + t x_1, \quad \epsilon \sim \mathcal{N}(0, \mathbf{I})$$

Notice that at $t = 0$, $x_t$ is pure Gaussian noise, while at $t = 1$, $x_t$ is the clean original image.

1.2 Classical Denoising (Gaussian Blur Baseline)

As a baseline, we attempt classical denoising using Gaussian blur. Since signal amplitude is scaled down by $t$, we first restore signal amplitude by dividing by $t$, and then apply a Gaussian filter $G_\sigma$:

$$\widehat{x}_1^{\text{blur}} = G_\sigma\left(\frac{x_t}{t}\right)$$

While Gaussian blur suppresses zero-mean high-frequency noise, it fails to recover structural detail at high noise levels ($t = 0.25$) because blurring destroys high-frequency edge information.

1.3 One-Step Denoising with Flow Model

Using the pretrained flow model velocity prediction $v_\theta(x_t, t, c)$ with prompt "a high quality photo", we extrapolate directly to the clean endpoint in a single step:

$$\widehat{x}_1 = x_t + (1 - t)v_\theta(x_t, t, c)$$

1.4 Visualizing Velocity & Error Heatmaps

We compare the model's predicted update $(1-t)\widehat{v}_t$ against ground-truth update $(1-t)v_{\text{gt}} = x_1 - x_t$. The spatial RMS error across RGB channels is calculated as:

$$E_t = \sqrt{\text{mean}_{\text{RGB}}\left(\left[(1-t)(\widehat{v}_t - v_{\text{gt}})\right]^2\right)}$$

The error heatmaps show that prediction errors are strongly concentrated along high-frequency object contours and fine background textures, especially at small $t$ where noise dominates.

1.5 Iterative Denoising with Euler Integration

Because velocity trajectories are curved, taking small iterative numerical integration steps with step size $h = 0.02$ yields dramatically higher quality reconstructions than one-step estimates:

$$x_{t+h} = x_t + h \cdot v_\theta(x_t, t, c)$$

PART A2: CLASSIFIER-FREE GUIDANCE (CFG)

To boost prompt adherence and image quality at the expense of sample diversity, we apply Classifier-Free Guidance (CFG). We compute conditional velocity prediction $v_c$ and unconditional prediction $v_u$ (empty prompt `""`), combining them with weight $w = 7.0$:

$$v_{\text{cfg}} = v_c + w (v_c - v_u)$$

PART A3: CREATIVE APPLICATIONS

3.1 Image-to-Image Editing (SDEdit)

By adding noise up to $t_{\text{start}}$ and denoising back to $t = 1.0$, we force images back onto the natural image manifold. Small $t_{\text{start}}$ values (e.g., $0.02 - 0.06$) allow severe structural halluncinations, while larger $t_{\text{start}}$ values ($0.25 - 0.50$) preserve low-frequency layout while refining textures.

PART B1: SINGLE-STEP DENOISING UNET

1.1 Architecture & Noising Process

We construct a UNet architecture comprising ConvBlocks, DownBlocks ($2\times$ downsampling), UpBlocks ($2\times$ upsampling), and skip connections. We train the network to remove noise from images corrupted with $\sigma = 0.5$ additive Gaussian noise ($z = x + \sigma \epsilon$).

1.2 Training & Results ($\sigma = 0.5$)

The denoiser $D_\theta(z)$ is trained using Adam ($\text{lr}=10^{-4}$) over 5 epochs with MSE loss $\|D_\theta(z) - x\|^2$.

1.2.3 Out-of-Distribution Noise Testing

We evaluate the trained denoiser on noise levels $\sigma \in [0.0, 1.0]$ that were not observed during training ($\sigma_{\text{train}} = 0.5$).

PART B2: FLOW MATCHING FROM SCRATCH

2.1 Time-Conditioned Flow Matching UNet

We extend our UNet by injecting scalar timestep $t \in [0, 1]$ using fully-connected FCBlocks to modulate intermediate layer feature maps. The model predicts path velocity $u_\theta(x_t, t) \approx x_1 - x_0$ under objective:

$$\mathcal{L}_{\text{flow}} = \mathbb{E}_{x_0, x_1, t}\left[\|(x_1 - x_0) - u_\theta(x_t, t)\|^2\right]$$

2.2 Class-Conditioned UNet & Classifier-Free Guidance

Adding class conditioning vector $c$ (one-hot vector) with 10% dropout ($p_{\text{uncond}} = 0.1$) enables targeted generation. During sampling, Classifier-Free Guidance with $\gamma = 5.0$ dramatically sharpens digit visual quality and class fidelity:

$$u_{\text{cfg}} = u(x_t, t, \emptyset) + \gamma \left(u(x_t, t, c) - u(x_t, t, \emptyset)\right)$$

2.3 Learning Rate Scheduler Ablation

Ablation Experiment: Removing the exponential learning rate decay scheduler ($0.1^{1/\text{epochs}}$).

Compensation Strategy: To maintain convergence without exponential decay, we set a flat initial learning rate of $\text{lr} = 2 \times 10^{-3}$ paired with a 1-epoch linear warmup. This prevents gradient instability early in training while maintaining fast convergence across 10 epochs without degrading sample quality.
